# 09 · Write the Fable design prompt — and tell Dustin to send it

Type: task (HITL)
Status: open
Blocked by: 04, 07, 08

## Question

What exactly goes to Fable, so it can invent a site that wows?

**This is the moment Dustin asked to be told about.** The output of this ticket is a paste-ready
prompt he relays to Fable — I do not design the site.

The prompt carries, and carries *only*:

- **The spine** — the one truth, its frozen number, the honest verb (ticket 07).
- **The data shape** — what fields exist, what a thread is, how many there are, what the
  pre/post-COVID split looks like.
- **The render budget** — max threads, technique, payload ceiling, blend rule, decimation
  (ticket 04). Non-negotiable; a design outside it cannot ship.
- **The hard constraints** — beautiful and fully functional on phone *and* desktop; near-wordless;
  premium bar; 3D permitted but only if depth encodes something; the mark must carry proportional
  volume itself, never a table or legend standing in for it.
- **The reference wall** (ticket 08) as inspiration to react to or reject.

The prompt carries **no house style, no template, no design skill, no prescribed form**. Fable
invents the mark and the visual language.

Ask Fable for **3–4 distinct directions**, each with enough substance to judge — not four variants
of one idea.

Resolution records: the prompt sent, and Fable's directions linked as assets.
