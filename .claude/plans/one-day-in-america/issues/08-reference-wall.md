# 08 · Build the reference wall and the honest positioning

Type: research
Status: open
Blocked by: 06

## Question

What does Fable get to react to, so its first pass isn't blind?

Assemble the anchor. Not a style guide — a wall of real things plus an honest statement of where
this site sits. Fable is free to reject all of it; it exists so the first round has gravity.

- **Pull real references** via Chrome MCP / Pinterest / Awwwards / Bremer / Lupi / Visual Cinnamon
  and anything else that fits. Target ~15–25 images, each with one line on *what specifically* is
  worth stealing (the light, the density, the palette, the mark, the restraint).
- **Generate 2–4 mood frames** with gpt-image-1 where a reference doesn't exist yet. Spend is
  authorized. State features positively — "not X" negatives do not work.
- **Honest positioning:** what this site is *and is not*, next to the four wow-mechanics the
  portfolio already uses (scale gasp / it's-about-you / beautiful object / you-produce-the-insight).
  Name which one this plays and why it isn't a rerun of a shipped project.
- **Anti-references:** two or three things it must not look like, with the reason.

Store images under `research/08-reference-wall/`. Output a single browsable page Dustin can look at
in one scroll, and a clickable link to it.
